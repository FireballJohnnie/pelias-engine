--- how to read this ---
THP 'always': 2 MB pages are used for large anonymous allocations. 'madvise': only programs that ask; llama.cpp does not,
so --load-mode none (which loads into ordinary anonymous memory) will use 4 KB pages. 'never': no huge pages.
If THP is not 'always', changing it is NOT done by this script. It needs root or a Windows-side .wslconfig kernel line
(restarts WSL, affects everything, effect on the WSL2 kernel unverified). Test 1b/1c first: if they gain enough, skip it.
